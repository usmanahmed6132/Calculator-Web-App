# Simple Interest Calculator

A simple, user-friendly web application designed to calculate simple interest based on the principal amount, annual interest rate, and time period provided by the user.

## Formula Used

The application calculates simple interest using the standard formula:

$$A = P (1 + rt)$$

Where:
- **P** = Principal Amount
- **r** = Annual Interest Rate (in decimal form)
- **t** = Time Period (in years)
- **A** = Total Amount accrued (Principal + Interest)

Simple Interest earned ($I$) is calculated as:
$$I = P \times r \times t$$

## Features

- **Input Validation:** Ensures non-negative numbers and valid numeric values for all fields.
- **Dynamic Calculation:** Calculates interest and total balance instantly upon submission.
- **Clear Interface:** Simple HTML/CSS/JavaScript interface for quick calculations.

## How to Use

1. Enter the **Principal Amount** ($).
2. Enter the **Annual Interest Rate** (%).
3. Enter the **Time Period** in years.
4. Click **Calculate** to display the interest accrued and total return.
